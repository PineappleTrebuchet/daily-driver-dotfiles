# Daily Driver Dotfiles
Very simplistic dotfiles for NixOS for both gaming and development. The aesthetic roughly (and I really mean _roughly_) mimicks the Windows 10 UI. Very functional while meeting a minimum aesthetic threshold, for me at least. Main WM is Sway but has Niri support. Bear in mind the Niri config has sway-like keybinds. This config is also ported to non-NixOS distros.

If you want to use these, remember to edit the wallpaper paths in wpaperd, swaylock, and the swaywm config as you will get errors if you don't update them yourself.

## List of stuff that is imperatively added
- Kicad libraries
- PCSX2 games and saves
- Steam compatibility tools added with protonup-rs
- Settings and profiles in Helium
